# 컷 추가 (Insert Shot)

장면 안에 클로즈업·리액션 컷을 **새 AI 영상 없이** 넣는 기능입니다. 승인된 클립을 FFmpeg로 잘라 확대하므로 **요금이 없습니다**.

## 사용
Script Studio의 장면 아래 "컷 추가" (또는 스토리보드의 "컷 편집") → 프리셋 선택(Jack 얼굴 · Diane 얼굴 · 눈 · 손/소품 · 제품 · 직접 자르기) → 전환 선택(하드 컷 · 즉시 펀치인 · 퀵 줌) → 시작 시간·길이 → 원본 화면에서 크롭 위치를 끌어 맞추고 배율 조정 → 저장. 오른쪽에 컷 결과 미리보기가 즉시 보입니다.

## 규칙
- 컷은 원래 장면의 **일부를 바꿔 끼웁니다**. 같은 클립을 같은 시간대에서 잘라내므로 **장면 길이·대사·한국어 자막·오디오 타이밍은 바뀌지 않습니다** (장면 밖으로 나가는 길이는 자동으로 줄이고, 겹치는 컷은 거부).
- 컷은 장면의 편집 가능한 샷 타임라인(`scene.inserts`)에 저장되고 버전 기록(`컷 편집 (S1)`)에 남습니다.
- 컷을 바꾸면 그 장면의 승인이 풀립니다(이전 승인본은 승인 기록에 보관). 컷이 있는 장면은 현재 버전이 승인되어야 렌더링할 수 있고, 컷이 바뀌면 이전 렌더는 "오래됨"이 됩니다.
- 대본 승인·스토리보드 승인·유료 생성 승인은 컷 때문에 바뀌지 않습니다 (그림만 바뀌는 무료 편집).
- **크롭은 카메라 이동일 뿐입니다.** 원본에 이미 있는 움직임을 확대할 뿐, 새로운 눈동자·표정 움직임은 만들지 않습니다. 눈/얼굴 프리셋에는 그 안내가 표시되고, 메모에 "눈이 움직인다" 같은 표현이 있으면 경고합니다. 실제 눈·표정 애니메이션은 별도의 AI 영상 생성(유료, 비용 확인·승인)이 필요합니다.
- **해상도 경고**: 원본에서 잘라낸 폭을 1080px로 확대하는 배율을 계산해 흐려질 수 있으면 경고합니다. 더 선명한 컷이 필요하면 "고해상도 이미지 필요"로 표시하고 스토리보드의 별도 비용 확인·승인 절차를 이용하세요 (여기서는 아무것도 생성하지 않습니다).
- 전환: 하드 컷 = 선택한 구도로 바로 전환 · 즉시 펀치인 = 첫 2프레임만 약간 더 확대한 뒤 안착 · 퀵 줌 = 약 0.3초 동안 빠르게 확대.
- 자주 쓰는 구도는 "프리셋으로 저장"해 다른 에피소드에서 불러올 수 있습니다 (`cut-presets.json`, 버전 관리). 에피소드/장면 복제·복사는 컷을 독립 데이터로 함께 가져갑니다. 이미지 디벨롭 이동 스냅샷에도 컷이 포함됩니다.
- 컷의 원본은 승인된 클립입니다. 클립이 아직 없으면 시작 이미지로 미리보기만 할 수 있고, 렌더링은 승인된 클립에서 합니다.

## API
`PUT /api/episodes/:id/scenes/:sid/inserts` · `GET/POST /api/cut-presets` · `DELETE /api/cut-presets/:id` · `GET /media/cutframe/:id/:sid?t=` (미리보기 프레임, 캐시됨)

테스트: `tests/insert-cuts.test.js` (실제 FFmpeg 렌더 포함: 컷 유무에 따른 출력 길이 동일, 렌더 신선도, 승인 게이트).
